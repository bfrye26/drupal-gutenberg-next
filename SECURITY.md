# Security policy

Gutenberg Next is currently an alpha project and has not received Drupal Security Team advisory coverage.

Do not report security vulnerabilities in a public issue. Until a dedicated private reporting channel is configured for the GitHub repository, contact the repository owner privately through GitHub.

The module does not replace Drupal access control. New adapters must enforce Drupal entity access, field access, CSRF protection and validation rather than trusting editor-side state.
